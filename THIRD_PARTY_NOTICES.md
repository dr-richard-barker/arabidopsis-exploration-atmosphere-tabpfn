The original selection and annotations in mixed CSV/JSON files are CC BY 4.0;
this does not grant rights over every third-party field. Titles, accessions,
sample descriptors, design values and file inventory facts have source URLs
and provenance. Long paper text, full API caches, expression tables and
biological measurement files are excluded.

- NASA OSDR, GEO/SRA and ENA: repository record and data-use policies apply.
  Public access is not asserted to be a universal CC license.
- BioStudies/ArrayExpress and PRIDE: source terms retained. PXD031138 declares
  CC0; PXD001815/PXD002353 declare EBI terms of use in retrieved metadata.
- Zenodo 16536514 v2: Silvia Lembo and credited contributors; CC BY 4.0.
  Only factual file/descriptive metadata, not workbooks, are included.
- Salk, CNGB and other atlas portals: source rights retained.
- Papers: cited and summarized, not redistributed.

Cite original studies/datasets as well as this catalog in downstream work.
Repository-reported file checksums are inventory metadata, not proof that
underlying data were downloaded or verified. PRIDE checksum fields without a
declared algorithm remain untyped rather than inferred from string length.
Zenodo page sizes are rounded; exact byte sizes remain missing.

The Zenodo upload-level CC BY 4.0 license describes original catalog content.
The description and bundled notices preserve the MIT code exception and
third-party terms. Recheck source terms before redistributing source content
beyond this factual extract.
